# HIT report

An experiment-report starter for Harbin Institute of Technology-style lab work.
It is an original example using the standard `article` class; the upstream
`hitreport` class is not bundled.

Compile with pdfLaTeX. The bibliography is intentionally small and fictional
so the document can be edited without copying upstream prose.

## Python setup (notebooks)

The notebooks in `notebooks/` need Python 3.10+. Create a virtual environment
and install the requirements from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
